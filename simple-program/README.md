# Programa de saludos

Ejecuta desde la carpeta principal del repositorio:

```sh
node simple-program/index.js
```

No requiere dependencias externas.

`index.js` importa la lista de `names.js` y la funcion `greet` de
`greeting.js` para mostrar un saludo por nombre:

```text
Hola, Ana!
Hola, Luis!
Hola, Sofia!
```
