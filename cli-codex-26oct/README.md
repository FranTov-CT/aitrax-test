# Calculadora de cinco números

Suma exactamente cinco números enteros de hasta tres cifras, entre -999 y 999
(ambos incluidos). El signo no cuenta como cifra. El resultado puede superar
tres cifras. Las entradas inválidas se vuelven a solicitar.

Requiere Python 3 y no necesita dependencias externas.

Desde la raíz del repositorio:

```sh
python3 cli-codex-26oct/calculadora.py
```

Para ejecutar las pruebas:

```sh
python3 -m unittest discover -s cli-codex-26oct -v
```
